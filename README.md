# 🌱 Hydrolink SCRUM + DevOps

**Hydrolink** es una aplicación IoT (Internet of Things) diseñada para **automatizar el control y gestión de recursos hídricos y energéticos** en una planta de riego agrícola.  
El sistema combina sensores, actuadores y una plataforma web que permite **monitorear, programar y optimizar** el uso del agua y otros recursos en tiempo real.

Proyecto académico para la activación técnica de **SCRUM + DevOps** en un entorno digital integrado.  
Este entorno conecta **Microsoft Teams**, **GitHub** y **Planner**, reflejando los artefactos y procesos de un marco ágil con pipeline DevOps básico.

---

## 🎯 Objetivo general

Reflejar los artefactos **SCRUM** en plataformas digitales, activar un **pipeline DevOps** y demostrar funcionalidad real mediante tres historias de usuario desarrolladas en un ambiente integrado.

Dev: Desarrollar un sistema integrado que permita **automatizar el riego agrícola** y **gestionar los recursos de la planta**, aplicando prácticas de **SCRUM** y **DevOps** para garantizar un desarrollo ágil, colaborativo y automatizado.

---

## 🧩 Descripción del proyecto

Hydrolink es un sistema IoT orientado al control y automatización de riego agrícola.  
En esta fase, se implementa un **ecosistema colaborativo** para la gestión ágil del desarrollo, aplicando los principios de **Scrum** y **DevOps**:

- Comunicación centralizada en **Microsoft Teams**
- Gestión ágil en **Planner (tablero Scrum)**
- Control de código y versionamiento en **GitHub**
- Integración entre herramientas (Teams ↔ Planner ↔ GitHub)

---

## ⚙️ Funcionalidades principales

- 🌱 **Monitoreo en tiempo real:** Lectura de sensores de humedad, temperatura y nivel de agua.  
- 💧 **Control automático de riego:** Activación de válvulas y bombas según condiciones definidas.  
- 📊 **Gestión de recursos:** Registro y seguimiento de consumos de agua y energía.  
- 🧾 **Módulo administrativo:** Control de clientes, cotizaciones, proveedores y compras.  
- 🔔 **Alertas y notificaciones:** Envío de avisos al detectar valores fuera de rango o fallas del sistema.  
- ☁️ **Panel personal:** Visualización y control centralizado desde cualquier dispositivo conectado.
